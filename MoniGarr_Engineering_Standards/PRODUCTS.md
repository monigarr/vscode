## How to Use This Catalog

1. Prefer the **Portfolio Taxonomy** below when browsing by channel or product class.  
2. Prefer the **Alphabetical Product Lexicon** when looking up a specific product name or repo.  
3. Each product entry should stay synchronized with its repository `README.md` and (when MES-conformant) project `PRD.md` / `ARCHITECTURE.md`.  
4. Visibility (`public` / `private`) and license terms must match GitHub and client contracts — do not invent public links for private repos.  
5. When adding a product: add taxonomy bullets, an alphabetical entry, and a `CHANGELOG.md` note for the MES suite if the catalog structure changes.  
6. **Language / community products** (including Indigenous language, tribal, or community-governed offerings) **shall** note sovereign/community data posture in **Notes** when applicable — and point to project `PRIVACY_DATA_GOVERNANCE.md` when that artifact exists.

### Entry template (copy for new products)

```markdown
### [Product Name]
| Field | Value |
|-------|-------|
| **Short description** | [one sentence] |
| **Repository** | https://github.com/monigarr/[repo] (public \| private) |
| **Status** | [Concept \| Active \| Maintenance \| Licensed \| Deprecated] |
| **Clients / audience** | [internal \| open source \| licensed clients \| TBD] |
| **MES conformance** | [Declared \| In progress \| N/A \| TBD] |
| **Primary capability** | [from GLOSSARY: Capability] |
| **Data classification** | [public \| internal \| PII \| CUI \| PHI \| sovereign \| N/A] |
| **Regulated profile** | [none \| see AI/REGULATED_PROFILES.md overlay] |
| **Owner** | [name] |
| **Last verified** | [YYYY-MM-DD] |
| **Notes** | [license, domain language, related products] |
```

**Rule:** No placeholder repository URLs. If the slug is unknown, write `Repository unknown — verify on GitHub` rather than a bare org URL.

### Product lifecycle states

| Status | Meaning |
|--------|---------|
| **Concept** | Named intent; no shippable repo or not yet Active |
| **Active** | Maintained repository / offering |
| **Maintenance** | Stable; limited feature work |
| **Licensed** | Client-licensed deployment of an Active product |
| **Deprecated** | Retained for history; do not start new work |

Move Deprecated entries to a **Deprecated** subsection (create when needed) rather than deleting them.
