## Purpose

This directory stores **auditable evidence** for:

- **MDES** — per-document or suite documentation excellence scores  
- **MCR** — MES Coherence Review findings  

Assertions of MDES Conformant, Conditionally Conformant, or MDES Excellence without evidence here (or an equivalent linkable PR artifact) are non-conformant.
